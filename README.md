# Grocery Store Customer Satisfaction AI

A college mini project using Python and Machine Learning to predict whether a grocery-store customer is satisfied or dissatisfied.

## Features
- Synthetic customer dataset with 1000 records
- Data preprocessing with a scikit-learn pipeline
- Random Forest classification
- Accuracy, classification report and confusion matrix
- Streamlit web application
- Satisfaction dashboard
- New-customer prediction

## Run

1. Install:
   `pip install -r requirements.txt`

2. Train the model:
   `python train_model.py`

3. Start the web app:
   `streamlit run app.py`

The app will open in your browser.

## Dataset
The included dataset is synthetic and intended for education/demo purposes. For a real project, replace it with genuine survey data collected with appropriate consent and privacy practices.
